# Private Voice Practice Checklist

A small checklist for people who want to record short voice-practice samples, notice patterns, and keep the process private.

Optional browser-based self-check: [Voice Gender Test](https://voicegendertest.com/).

## Files

- `checklist.md` — printable practice checklist.
- `session-template.md` — one-page session log.
- `privacy-notes.md` — privacy considerations for voice recordings.

## Intended use

This resource is for personal practice, coaching preparation, classroom discussion, and self-reflection. It is not a medical, diagnostic, or identity-determining resource.
